# 接入說明（通用，不分工具）

做法只有一個：**讓你的 agent 在任務開始與結束時，執行一行指令。**

```bash
python3 scripts/set_state.py <角色id> working "任務名稱（10 字內）"   # 開始：角色走去坐下
python3 scripts/set_state.py <角色id> idle                            # 結束：角色離座休息
```
只用 Python 標準庫。能執行 shell 指令的 agent（Claude Code、Codex、其他終端機型 agent）都適用。

想讓角色說一句話（頭上冒出對話泡泡約 6 秒，狀態與任務不變）：
```bash
python3 scripts/set_state.py <角色id> say "要說的話（40 字內）"
```
多個 agent 各綁一個角色，就能在畫面上互相對話；沒有指定時，角色會依 `dialogue.json` 自動說話。

## 怎麼讓 agent 記得執行
把下面這段貼進 agent 的規則檔（Claude Code 用 `CLAUDE.md`、Codex 用 `AGENTS.md`、其他工具用它的系統提示或規則檔）：

```markdown
## Office 角色狀態
- 開始處理任務時執行：`python3 <路徑>/teahouse-office/scripts/set_state.py <角色id> working "任務名稱（10 字內）"`
- 任務完成或等待我回覆時執行：`python3 <路徑>/teahouse-office/scripts/set_state.py <角色id> idle`
```
把 `<路徑>` 換成放這個資料夾的位置、`<角色id>` 換成你的角色（如 `mochi`）。

## 想要完全自動、不靠 agent 記得（選用）
工具若支援 hook（Claude Code 支援），可以用 `scripts/hook_state.py`：送出訊息→working（任務名＝訊息前 10 字），回合結束→idle。
把下面合併進 `settings.json`，`/ABS/PATH` 換成絕對路徑：

```json
{
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "python3 /ABS/PATH/teahouse-office/scripts/hook_state.py mochi" }] }],
    "Stop":             [{ "hooks": [{ "type": "command", "command": "python3 /ABS/PATH/teahouse-office/scripts/hook_state.py mochi" }] }]
  }
}
```

## 不能執行指令的聊天機器人（如 Grok bot）
它碰不到你的電腦，只能當「寫文字的助手」：請它依 `references/01～03` 產出人設卡、對白 JSON、生圖提示詞，由你自己存檔與跑腳本；狀態則手動執行上面的指令，或直接改 `app/public/data/state.json`。

## 驗證狀態
- `set_state.py`、`hook_state.py`：已用模擬輸入實測（正常、亂輸入、角色不存在都不出錯）。
- **還沒有在真實的 Claude Code／Codex／Grok 工作階段裡實際跑過整條接入**，也沒驗證 Codex 會不會照規則檔每次都執行、Grok 能不能穩定輸出可用 JSON。設好後請自己試一次：開 Office 頁面、給 agent 一個任務，看角色有沒有動。
- 生圖：Codex 實測能直接出透明底（從零做一個角色走完全程）；其他工具沒測，提示詞 D1／D2 兩套都附了。
