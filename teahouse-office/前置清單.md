# 開工前置清單（先勾完，再開始流程）

## A. 工具盤點
**必要**
- [ ] AI agent（擇一）：Claude Code／Codex／Grok bot
- [ ] 生圖工具：能出多格拼圖、最好能給透明背景（如 ChatGPT／Codex 生圖）
- [ ] Node.js 20.19 以上（或 22.12 以上）與 npm　檢查：`node -v`、`npm -v`
- [ ] Python 3 與 Pillow　檢查：`python3 -c "import PIL; print(PIL.__version__)"`
- [ ] 瀏覽器（Chrome 等）

**選用**
- [ ] Playwright（自動截圖驗收）
- [ ] Blender（只有想進階做 3D 角色才需要，本套件不依賴）

## B. 角色準備（每個角色一份，複製這段）
**角色 ＿＿＿＿**
- [ ] 名字
- [ ] 職務（在 Office 負責什麼）
- [ ] 個性三個詞
- [ ] 口頭禪或說話風格
- [ ] 外型：物種／人型、髮色、服裝、配件
- [ ] 主色與輔色（最多 3 色）
- [ ] 參考圖（選用，勿用有版權角色或他人作品當成品）
- [ ] 身高設定（多角色時：等身高或按比例）
- [ ] 動作必備：站（前／後／側）、走（前／後／側）、坐著工作
- [ ] 動作選配：講話、揮手、看書、喝茶、伸懶腰等休息小動作
- [ ] 喜歡待在場景哪裡（書桌、窗邊、庭院…）

## C. 整體設定
- [ ] 角色數量（第一次建議 1–4 位）
- [ ] 場景（目前提供和風庭院；座位分在書齋、會議和室、工房、藏書室、展示和室）
- [ ] 色調偏好
- [ ] 要不要日夜或季節感

## D. 通過條件
全部勾完、環境檢查通過，才進流程第 1 步。缺項由 skill 逐項提問補齊，不替使用者決定。
