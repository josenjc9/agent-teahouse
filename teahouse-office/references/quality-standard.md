# 質感標準（Office 套件的畫面底線）

> 這份是畫面質感的規格：成品未達標準即視為未完成，即使功能檢查全數通過。
> 驗收順序：先目視評估成品本身，再用清單找出落差；清單用來發現問題，不用來證明品質。

## 1. 渲染管線（引擎層，所有場景預設共用，不准關）
| 項目 | 標準值 | 為什麼 |
|---|---|---|
| 陰影 | `shadows="soft"`，主光 2048 貼圖、`shadow-radius` 3，靜態場景只在需要時重算 | 沒有陰影，方塊就浮在地上、像模型不像場景 |
| 色調映射 | ACES Filmic | 避免高光死白、暗部死黑，畫面有電影感 |
| 泛光 Bloom | 強度 0.75（黃昏）、門檻 0.92、`mipmapBlur` | 讓窗燈、石燈「真的在發光」 |
| 暗角 Vignette | 黃昏 0.55 | 視線收進主體 |
| 天空 | 自訂漸層天空（上／中／地平／下／深五段色）＋太陽光暈；同一份天空當環境光源（Environment） | 天空色決定整個場景的色溫 |
| 霧 | 顏色跟天空地平線同色系，near 60／far 150 | 遠處不硬切、有空氣感 |
| 光 | 暖色主光（黃昏 `#ff9f66`、強度 3.4）＋冷色補光＋半球光 | 暖冷對比是質感來源 |
| 發光材質 | 窗紙、石燈用 emissive；亮度隨時段調（白天 0.12 倍、夜晚 1.5 倍） | 夜景的靈魂 |
| 底座 | 浮島底座＋底下的雲 | 把場景變成「一個小世界」 |
| 角色 | 精靈圖永遠面向鏡頭、`toneMapped:false`、腳底接觸影、alphaTest 0.04 | 角色不被色調映射洗掉、不浮空 |

時段設定表在 `app/src/presets/japanese-garden/tod.ts`（dusk／day／night）。**換場景、加時段都要有自己完整的一組值，不能只換背景色。**

## 2. 場景手工細節（預設場景層）
- 材質有貼圖與紋理：木紋、榻榻米、紙窗、瓦片、苔蘚、碎石（程式畫在 canvas，不依賴外部檔）
- 每個空間至少有 3 種「活的」細節：發光物、水面或植物、擺設（石燈、盆栽、紅傘、小橋、魚、浮雲）
- 沒有裸方塊：每個形體至少有倒角、尺寸變化或貼圖其中一項
- 比例與人物對得上：門高約 2.4、屋簷底約 2.95、人物站高約 1.86（場景單位≈公尺）

## 3. 角色圖（使用者自己生的圖）
- 全身、單一角色、透明背景、腳底在固定高度；整套同一畫風、同一線條粗細
- 半透明霧像素（肉眼可見的淡色殘影）比例：乾淨低於 1%，**超過 3% 判有底霧，要清理或重生**（透明度 10% 以下的極淡斑點不計）
- 動作首尾能銜接；不要停在最後一格
- 多角色等身高（除非刻意設定）
- 不帶場景道具（長椅、水面）進圖

## 4. 介面
- 玻璃質感：半透明底＋模糊＋細邊，暖色（白天改淺色版），一個強調色
- 頂部分頁膠囊、底部角色列，不蓋住場景主體
- 手機（寬 < 760）不溢位、可操作

## 5. 驗收方式（三步，缺一不算完成）
1. **自動檢查**：`python3 scripts/check_quality.py` 驗引擎層設定都在、時段表完整
2. **真實截圖**：用瀏覽器開起來，截三張（白天／黃昏／夜晚），附在交付裡
3. **並排比對**：把截圖跟本套件預設場景的截圖並排放，逐項看：陰影有沒有、窗燈亮不亮、色溫對不對、角色有沒有浮空或被洗白、介面有沒有蓋住主體。目視上與預設場景有明顯落差者，視為未達標，退回修改

## 6. 常見退化（出現就退回）
- 平光無陰影、純色天空 → 缺管線
- 窗燈沒發光、夜景一片黑 → emissive 沒隨時段調
- 角色周圍有白邊或霧 → 底霧沒清
- 角色比門還大或腳沒踩地 → 比例或接觸影
- 介面蓋住場景一半以上 → 版面
